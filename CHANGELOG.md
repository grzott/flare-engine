# Changelog

Flare versions **in lockstep**: every `@flare-engine/*` package shares one version and moves
together on every release, so "Flare 0.3.1" names the whole set rather than any single package.
That is enforced by the `fixed` group in [`.changeset/config.json`](.changeset/config.json).

This file is the index. **Per-package detail lives in each package's own `CHANGELOG.md`**
(`packages/<name>/CHANGELOG.md`), generated by Changesets — that is the source of truth for what
changed in a given package, and it is not duplicated here.

> **Availability.** Every release below was published **restricted** to npm, not public. The
> `@flare-engine` scope is not installable without authentication today; that changes at the
> October 2026 public flip. See [`docs/plans/road-to-oss-2026-09.md`](docs/plans/road-to-oss-2026-09.md).

## 0.4.2

A freeze-window fix, shipped alone. Only `render` and `render-web` changed; every other package
moves in lockstep.

- **`render` / `render-web`** — `tint` and `flash` keep the sprite's alpha, so a frame's transparent
  padding stays transparent instead of being painted with the effect colour; a sprite whose art does
  not fill its frame no longer flashes as a rectangle
  ([ADR-0009](docs/design/adr-0009-tint-flash-src-atop.md)). Fully opaque pixels are unchanged;
  anti-aliased edges and glows keep their coverage, so a soft edge under `tint` reads slightly
  thinner. `render-web`'s CanvasKit adapter maps the new blend mode, without which the fix would have
  been a no-op on web.

## 0.4.1

A freeze-window fix, shipped alone. Only `errors` changed; every other package moves in lockstep.

- **`errors`** — `createSentryTransport` starts Sentry with the SDK's own capture switched off, so
  Sentry sends only what the transport is given and a consent check in front of it holds
  ([ADR-0008](docs/design/adr-0008-sentry-transport-auto-capture-off.md)). Events sent through
  `report()` keep their stack frames, release and debug-meta but lose the device context and
  breadcrumbs the dropped integrations attached. Route process-wide JavaScript errors through
  `installGlobalErrorCapture`. On Android 11+ the native SDK still reports past ANRs on its own;
  the ADR names the manifest switch.

## 0.4.0

The freeze cut before the October public flip. Its two breaking changes were each decided in an
accepted ADR while the scope is still restricted. Until the flip, only fixes ship, as `0.4.x`
patches.

**Breaking**

- **`react` requires the New Architecture** ([ADR-0002](docs/design/adr-0002-worklets-migration-and-new-arch-floor.md)).
  It now peers `react-native-reanimated >=4.0.0` and `react-native-worklets >=0.7.0`, and dispatches
  the native scene capture through `scheduleOnUI` instead of Reanimated's deprecated `runOnUI`. Every
  `@flare-engine/create` template already ships both at these versions.
- **`render` — `SpriteDrawCommand` gains three required fields**, `blend`, `flipX` and `flipY`
  ([ADR-0006](docs/design/adr-0006-sprite-command-required-fields.md)). Code that builds a command
  literal must supply them.

**New**

- **`@flare-engine/create`**, first publish — the scaffolder, now inside the scope
  ([ADR-0007](docs/design/adr-0007-scaffolder-is-flare-engine-create.md)). Run
  `npm create @flare-engine my-game` or `bunx @flare-engine/create my-game`. The unscoped
  `create-flare-app` belongs to an unrelated package; `flare new` now runs `@flare-engine/create`
  pinned to the CLI's own version.
- **`render`** — additive blend, `flipX` / `flipY`, `drawNineSlice`, and opt-in `cullBounds` on the
  sprite batch.
- **`particles`** — emitter shapes, and `drawParticles` to queue live particles into a caller-owned
  sprite batch.
- **`physics`** — minimum-translation vectors and a broadphase-backed world raycast. Exactly-touching
  shapes now never collide, across every shape pair.
- **`math`** — curves, segment intersection points, and RNG state.
- **`errors`** — captures the crashes `ErrorBoundary` cannot see.

**Fixes**

- **`react`** — `<GameView>` rendered a black frame on device; the native capture surface is now
  built on the UI thread. The `safeArea` zero-insets fallback the docs promised now exists.
- **`storage`** — `DocumentStore.load()` no longer writes a fallback over a stored document it could
  not read.
- **`pathfinding`** — the open-set heap grows instead of corrupting past 4096 entries.
- **`ecs`** — `Query` removal is O(1).
- **`cli`** — `flare tiled-to-flare` emits Tiled-shaped JSON that `parseTiled` accepts.
- **`input`, `deep-links`** — URL and input parsing hardened against inherited keys and non-finite
  values.
- **`engine`** — declares the `react-native-reanimated` peer on the barrel.

**Published-surface settlement** ([ADR-0004](docs/design/adr-0004-pre-flip-surface-remediation.md)).
The pre-flip audit's contract changes across `core`, `math`, `ecs`, `input`, `shapes`, `render`,
`render-web`, `postfx`, `react`, `scene`, `storage`, `physics`, `pathfinding`, `tilemap`, `cli`, `ui`,
`ui-shop`, `iap-revenuecat`, `leaderboards` and `devtools` — read each package's changelog before
upgrading. For example, `SceneFactory` now receives the `World` and `Camera2D` the manager created
(a zero-argument factory still type-checks), and `TileLayer.tiles` is `readonly`.

**Performance.** The new blend, flip and cull checks cost the node `render.flush` microbenchmarks
10–15% (`1000 sprites / 1 atlas` 22.8 → 26.0 µs). The CanvasKit frame lanes moved −6% to +2.5%.
See [benchmarks](docs/references/benchmarks.md).

## 0.3.1

Fixes driven by the two real consumers (Pan Tvardowski and a portfolio site), all shipped as
patches because both consumers pin `^0.3.0` and a minor would have reached neither.

- **`physics`** — uniform spatial-hash broadphase behind the existing `SpatialIndex` surface;
  the exported API is unchanged. Sparse-scene collision cost dropped from 4.82 ms to 0.18 ms at
  1000 bodies.
- **`react`** — `VirtualButton` and `VirtualJoystick` can now be used together; pointer identity
  comes from the touch event instead of a hard-coded id 0.
- **`ui`** — `Label` gained `numberOfLines` / `ellipsizeMode` / `adjustsFontSizeToFit` /
  `minimumFontScale`; `style` widened to `StyleProp<…>` across all eight prop declarations.
- **`ecs`** — optional `query?` on `createLifetimeSystem` and `createBoundsCullSystem`, so callers
  can supply a pre-registered query instead of the systems minting their own.
- **`postfx` / `render`** — `uniforms` widened to `Float32Array | number[]`, removing an
  `as unknown as` bridge from a consumer that bans `any`.
- **`physics`** — `getColliderBounds` / `getColliderBoundsInto` on `CollisionWorld`.
- **`scene`** — a generation token retires stale `onPreload` handlers, fixing an activation stall.
- **`dynamics`** — `BodyOptions`, `WorldOptions` and `isStatic` exported from the barrel.

## 0.3.0

The consumer-enablement release: the first cut with real external consumers of the packages it
ships.

- **Web target.** `<GameView>` renders in a browser from the same source that builds the native
  app; all three `create-flare-app` templates gained web support, and two per-frame leaks in the
  web scene-capture path were fixed.
- **New package: `@flare-engine/dynamics`** — rigid-body dynamics, its first release.
- **Toolchain.** Bundling moved from `tsup` to `tsdown`, lint to Biome 2, the TypeScript floor to
  5.9. Dist output is byte-compatible; no runtime or public API change.
- **Packaging.** Every manifest declares `engines: { node: ">=20" }`, and per-condition type
  declarations mean an ESM consumer resolves `.d.mts` rather than falling back to the
  CommonJS-flavoured `.d.ts`.
- **Documentation truth pass.** Every `ts`/`tsx` README example now typechecks against the
  workspace, enforced in CI by `bun run check:readme`.
- **Correctness.** The bulk of the pre-launch audit rows (`OSS-B*`), plus perf-observability
  counters and a hot-loop `__DEV__` guard.

## Conventions

- **Lockstep.** Never bump a single package. A release moves every `@flare-engine/*` together.
- **Never a major.** A major on any package would force the whole lockstep set to 1.0.0.
- Releases are cut with Changesets; see [`AGENTS.md`](AGENTS.md) for the commit and versioning
  contract.
