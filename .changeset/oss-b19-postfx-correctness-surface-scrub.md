postfx: correctness slivers + public-surface scrub. `SkiaRuntimeEffectLike.makeShaderWithChildren` now types its uniforms parameter as `Float32Array` (was `ArrayLike<number>`), closing the type hole that let a caller pass a plain `number[]` that some CanvasKit builds silently truncate past index 4 — full-length uniform arrays (god-rays' 12 floats, etc.) now reach the shader by construction. Weather clouds gain a real `direction`: `WEATHER_CLOUDS_SKSL` takes a `direction` uniform and scrolls the cloud field along the rotated axis (`direction=0` reproduces the previous pure-horizontal scroll), and `direction` is packed into the effect's uniform buffer. The dead `speed` field is removed from `WeatherRainUniforms` and `WeatherCloudsUniforms` (and both factories) — it was declared but never reached any shader; per-frame phase advance stays a caller responsibility (`scrollOffset*`). `createPostFxRuntime` gains an optional second argument `{ verbose?: boolean }`; the first-compile diagnostic `console.info` is now gated behind `verbose` (compile-failure `console.warn` is unchanged), so a released build is silent by default. Shipped doc comments in `controller.ts` are rewritten project-neutral (no game/session/phase vocabulary in the public `.d.ts`).
