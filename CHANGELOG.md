# Changelog

Flare versions **in lockstep**: every `@flare-engine/*` package shares one version and moves
together on every release, so "Flare 0.3.1" names the whole set rather than any single package.
That is enforced by the `fixed` group in [`.changeset/config.json`](.changeset/config.json).

This file is the index. **Per-package detail lives in each package's own `CHANGELOG.md`**
(`packages/<name>/CHANGELOG.md`), generated by Changesets — that is the source of truth for what
changed in a given package, and it is not duplicated here.

> **Availability.** `0.1.0` through `0.4.4` were published **restricted**. On 2026-10-26 the
> `@flare-engine` scope went public, and npm visibility is retroactive, so every version below
> installs without authentication. `0.4.5` is the first release published as public, from CI with
> npm provenance. See [`docs/plans/road-to-oss-2026-09.md`](docs/plans/road-to-oss-2026-09.md).

## 0.4.11

Additions, fixes and internal refactors in 17 packages. The other 25 change only their version.

- **`progression`** — `createGameClock(config, state?)` is a 1440-minute game-day clock whose
  ordered segments each run at their own real-seconds-per-game-hour rate. `update(dt)` lands exactly
  on every boundary it crosses. `advanceMinutes` and `skipTo` move it in game minutes, `pause` and
  `resume` stop and restart it, and `hold` stops it at the next phase boundary until `release`. It
  has `onSegmentChange` and `onPhaseChange` callbacks, and a plain `serialize()` state restores
  through the second argument.
- **`animation`** — `updateSpring` advances with the exact damped-oscillator solution instead of one
  semi-implicit Euler step of the whole `dt`. A clamped 0.25 s hitch frame no longer blows a default
  spring up, and n steps of `dt` equal one step of n·`dt`. Trajectories at ordinary frame rates
  differ slightly from the old steps; settle thresholds and `atRest` are unchanged. `tween()` without
  an `easing` now defaults to `linear` from `@flare-engine/math`, so
  `tween(0, 1, 1).easing === linear` holds. Values are unchanged.
- **`create`** — the `blank`, `topdown` and `shmup` templates move from Expo SDK 57 to Expo SDK 58:
  React Native 0.88.1, React 19.3.0, `@shopify/react-native-skia` 2.14.0, and Reanimated 4.7.1 with
  worklets 0.13.0. `canvaskit-wasm` stays at 0.41.0, the version RN-Skia 2.14.0 pins.
- **`scene`** — a `go()` issued while an animated `go()` is still fading out now destroys the
  superseded target (`onDestroy`, never `onInit` or `onEnter`) and drops it from the cache, so a
  later `push()` or `go()` of that name builds a fresh instance. `destroy()` does the same to a
  pending target. An instant `go()` ends any transition in progress, so a stale target can no longer
  replace the new scene.
- **`dialogue`** — `updateTextReveal` treats `punctuationDelay` as extra time, so the gap after a
  `.!?:;` is `1 / speed + punctuationDelay`, as documented. Before, `punctuationDelay` replaced the
  gap: the extra delay was about 0.117 s instead of 0.15 s at the default 30 cps, and text slower
  than about 6.7 cps sped up after punctuation. `updateTextReveal` also no longer rebuilds
  `visibleText` while the revealed count is unchanged, so a caller that overwrites `visibleText` with
  a string of the same length keeps it until the count changes. The `ActionHandler` JSDoc now states
  that the runner does not await a returned promise.
- **`ui`** — `Button` no longer unregisters and re-registers its focus node when a parent re-render
  passes a new `onPress` identity or changes `disabled` or `tabIndex`, so keyboard focus and tab
  order survive re-renders. `FocusManager.register` of an already-registered id updates that node in
  place, `activate()` skips a disabled focused node, and the disposer that `register` returns works
  destructured.
- **`share`** — `createNativeShareTransport` passes a `screenshot` to RN `Share` as a `data:` URL
  when the payload sets no `url`, so iOS attaches the image; an explicit `url` still wins. On
  Android, where RN's `Share` forwards only `title` and `message`, a screenshot-only payload now
  opens an empty sheet that reports `dispatched: true` instead of rejecting.
- **`achievements`, `storage`** — `createStorageAchievements` no longer caches a failed hydration:
  when `store.get` rejects, that call rejects and the next call reads again. `createIndexedDbAdapter`
  likewise retries a failed `indexedDB.open`. `createStorage` no longer writes a `__flare_version`
  key on `saveSlot`, and `createDocumentStore` no longer writes `__flare_doc_version`. Nothing read
  either key, and keys already in a store are left in place.
- **`debug`** — with `new DebugOverlay({ reuseCommands: true })`, `drawRect`, `drawCircle` and
  `drawLine` reuse pooled command objects, which change after `clear()`. Without the option every
  call still creates a fresh object. `createFrameBudget` keeps a running fps sum instead of
  re-summing its ring on every `recordFrame`. After a non-finite `dt`, `getAvgFps()` reads 0 for
  under two ring lengths, where it was one before.
- **`pathfinding`** — `findPath` and `findPathJPS` keep their search scratch per `Grid` and reuse it,
  so a repeat search allocates no typed arrays unless its open set outgrows the kept heap.
  `findPathJPS` scans jumps in a loop, so a long open corridor no longer overflows the stack on V8
  and Hermes. `findNavMeshPath` keeps a per-mesh id index and computes each centroid at most once per
  search. Results are unchanged.
- **Internal refactors, no behaviour or API change** — `audio` (`Music` track start), `create`
  (`--template` parsing), `engine` (the main entry re-exports `@flare-engine/engine/headless`; the
  exported names are unchanged), `errors` (one payload-to-`Error` helper for both transports), `iap`
  (`getGrantsForProduct`), `progression` (`resolveTier`), `scene` (stack teardown), `shapes` (one
  fill-then-stroke helper), `simulation` (`NBodySystem.step` calls `verletStep`) and
  `storage` (one envelope guard).

## 0.4.10

Additions and fixes in 21 packages. The other 21 change only their version. 0.4.9 was versioned on
`main` but never published, because its release run stopped at the perf-freshness gate. Its two
`scene` changes ship here, and each package's own `CHANGELOG.md` still lists them under 0.4.9.

**Deprecation:** `SystemDef._worldFn` (`ecs`) is deprecated in favour of `SystemDef.worldFn`, which
is the same function reference. `_worldFn` stays until the next planned minor.

- **`scene`** (from 0.4.9) — `SceneManager.push(name, data?, { overlay: true })` updates and draws
  the new scene above the one below instead of replacing it, and the scene below gets no `onExit` on
  the push and no `onEnter` on the matching `pop()`. `pop({ keep: true })` leaves the popped scene
  initialized, so the next `push` of its name goes straight to `onEnter`. `pop({ data })` forwards
  `data` to the revealed scene's `onEnter`. A plain `push` or `pop` is unchanged.
- **`audio`** — `renderSynth` renders procedural SFX into a caller-owned `Float32Array` without
  allocating. Waveforms are sine, square, saw and seeded noise, with an ADSR envelope and a frequency
  sweep. `synthSampleCount` sizes the array and `fillPCMBuffer` copies it into a buffer.
  `PlaySFXOptions.delay` schedules a cue on the audio clock. Fix: `SFXPool` and `Music` registered
  `onended` while `react-native-audio-api` exposes `onEnded`, so finished voices were never released
  and `Music.playing` stayed set after a non-looping track ended.
- **`dynamics`** — opt-in per-body sleeping, off when the option is absent: `createWorld({ sleep })`,
  `isSleeping`, `isAtRest` and `wakeBody`. `stepUntil` and the zero-alloc `stepUntilInto` step until a
  predicate holds, a step cap is reached or a time budget runs out. `createTimeline` records a
  fixed-step simulation once into a pre-allocated `Float32Array` and replays it with `sampleInto`.
- **`render`, `render-web`** — `FrameRenderer.setImageSampling(image, 'nearest' | 'linear')` sets
  the sampling of one image on both draw paths, so pixel art scaled through `drawAtlas` stops
  blurring. An image with no setting draws as before. A flipped sprite now draws with its `rotation`,
  so Tiled's diagonal-only and all-three-bits tiles get the quarter turn 0.4.8 still left out.
- **`react`, `render`** — `GameView` runs a bound postfx chain on web, composited inside the scene
  capture on the existing offscreen surface, and the one-time "postfx chain skipped" warning is gone.
  Native is unchanged. `FrameRenderer.compilePostFxPasses` returns the runtime's compiled passes.
- **`tilemap`** — `parseTiled` reads Tiled per-tile animations onto `TilesetRef.animations`. With
  `TilemapDrawOptions.time` (seconds), each animated tile draws its current frame, with no allocation
  in the tile loop. Without `time` the authored tile draws as before.
- **`storage`** — `saveSlot(name, data, header?)` stores an optional header beside the data.
  `listSlotHeaders()` returns every slot's `{ name, version, header }` from the slot envelope alone,
  running no migration. The new `parseHeader` option repairs stale stored headers when they are listed.
- **`errors`** — `SentryTransportOptions` gains an `integrations` hook that decides what Sentry's
  `init` receives. `CrashTransport` gains an optional `close()`, which the Sentry transport awaits and
  `composeTransports` forwards. Fix: with no previous React Native global handler, `uninstall()` left
  the capture's `ErrorUtils` handler live.
- **`input`** — while no primary touch is active, `InputManager.onPointerMove` treats a move for an
  id that was never pressed as a hover. `pointer.position` and `pointer.delta` follow it, and no
  phantom pressed touch is recorded.
- **`physics`** — `buildSolidGrid(…, { outside: 'open' })` lets a body walk off the map edge, for
  seams between region maps. The default still blocks.
- **`shapes`** — `BaseSpec.glow` also takes `{ color, width }`. `shapeBoundsBox` and the zero-alloc
  `shapeBoundsBoxInto` return the bounding box of a composition.
- **`ui`** — `@flare-engine/ui/focus` is a new entry point with only the focus core. It imports
  neither `react` nor `react-native`. `Button.focusOnPress` and
  `FocusManagerOptions.refocusOnUnregister` turn off two focus side effects. Both default to `true`.
- **`testing`** — `createHeadlessContext(opts?)` is an RN-free, Skia-free stand-in for the React
  `GameContextValue` (without `audio`, `renderer` and `batch`) for loop-harness tests.
  `@flare-engine/assets` and `@flare-engine/render` become dependencies of the package.
- **`create`** — the `flare-create` next-step hint names the detected package manager and
  `run android`, instead of a hard-coded `bun run start`. The shmup template uses `sys.worldFn`.
- **Exported types** — option and payload types that exported signatures already used can now be
  imported:
  - `debug`: `FrameBudgetOpts` and `PerfRecorderOpts`;
  - `deep-links`: `WebWindowLike`;
  - `input`: `NavigatorLike` and `WebGamepad`;
  - `share`: `WebNavigatorLike` and `FileCtorLike`;
  - `iap-revenuecat`: its four SDK payload types;
  - `react` and the `engine` umbrella: `SkOffscreenSurfaceLike`.

  `shapes`' emitted declarations no longer carry a generated dollar-one-suffixed alias.

## 0.4.8

Fixes in `@flare-engine/tilemap`, `react`, `render-web` and `errors`. The other 38 packages change
only their version.

- **`tilemap`** — `TilemapRenderer` draws Tiled's flip bits instead of stripping them. A
  horizontally or vertically flipped GID draws mirrored, and the diagonal bit becomes a quarter turn
  combined with the flip Tiled defines. Two combinations need both a flip and a turn: the diagonal
  bit alone, and all three bits. They queue the correct command but still draw without the turn,
  because `@flare-engine/render`'s flip path does not yet apply `rotation`.
- **`tilemap`** — `TileLayer.opacity` is drawn, so a layer authored at 40% renders at 40%.
  `drawInto` and `draw` take an optional third argument, `{ effect?, alphaScale? }`
  (`TilemapDrawOptions`). It sets one effect on every tile and scales each layer's opacity. The
  two-argument calls are unchanged.
- **`react`** — the native `GameView` binds a postfx pass's image children, so the color-grading
  LUT pass (`createColorGradingLut`) grades on device instead of being dropped. A chain without
  image children renders as before.
- **`render-web`** — `loadCanvasKit` downloads `canvaskit.wasm` once on `canvaskit-wasm` 0.41+,
  instead of fetching the binary a second time after the progress bar reached 100%. On the
  simulated 4G profile, cold start falls from 32.5 s to 16.7 s. One cost was measured: with
  CanvasKit's software rasterizer (no WebGL), the two heaviest benchmark scenarios draw 7–16% slower.
  The WebGL lanes, desktop and Android, are unchanged. This is tracked in
  [#210](https://github.com/grzott/flare-engine/issues/210).
- **`errors`** — `installGlobalErrorCapture` and `ErrorBoundary` catch a transport whose `report`
  rejects, and log it as they already logged a synchronous throw. Before, a rejecting `async report`
  on web looped through the capture's own `unhandledrejection` listener until the transport
  recovered. The bundled transports were not affected.

- **`cli`** — `flare tiled-to-flare` now names a TMX (XML) input instead of failing inside the JSON

  2 to 3. Neither changes what the CLI exports or how its commands behave. commander 14 requires

## 0.4.4

A freeze-window fix, shipped alone. Only `react` changed; every other package moves in lockstep.

- **`react`** — `<VirtualJoystick>` follows its own finger on device, so the knob no longer jumps on
  Android or leaves its ring when you drag past the edge
  ([ADR-0011](docs/design/adr-0011-joystick-reads-its-own-finger.md)). It takes its page origin when
  the touch starts, follows that finger by its identifier in page coordinates, and ignores other
  fingers, so a second finger on a fire button no longer steers the stick. The default knob is no
  longer a touch target, matching the `base` and `thumb` slots. Web behaviour is unchanged, and no
  exported name, signature or type changes.

## 0.4.3

A freeze-window fix, shipped alone. Only the package metadata of `audio` and `engine` changed; no
code changed, and every other package moves in lockstep.

- **`audio` / `engine`** — `react-native-audio-api` is now an optional peer, so npm and bun no longer
  install it into every app that depends on `engine`. Neither package imports it. As a required peer
  it was compiled into every Android build, starter templates included, and on Windows that build
  cannot complete, so no template could build for Android there
  ([ADR-0010](docs/design/adr-0010-audio-api-optional-peer.md)). An app that plays audio on native
  adds it itself: `bun add react-native-audio-api`.

## 0.4.2

A freeze-window fix, shipped alone. Only `render` and `render-web` changed; every other package
moves in lockstep.

- **`render` / `render-web`** — `tint` and `flash` keep the sprite's alpha, so a frame's transparent
  padding stays transparent instead of being painted with the effect colour; a sprite whose art does
  not fill its frame no longer flashes as a rectangle
  ([ADR-0009](docs/design/adr-0009-tint-flash-src-atop.md)). Fully opaque pixels are unchanged;
  anti-aliased edges and glows keep their coverage, so a soft edge under `tint` reads slightly
  thinner. `render-web`'s CanvasKit adapter maps the new blend mode, without which the fix would have
  been a no-op on web.

## 0.4.1

A freeze-window fix, shipped alone. Only `errors` changed; every other package moves in lockstep.

- **`errors`** — `createSentryTransport` starts Sentry with the SDK's own capture switched off, so
  Sentry sends only what the transport is given and a consent check in front of it holds
  ([ADR-0008](docs/design/adr-0008-sentry-transport-auto-capture-off.md)). Events sent through

## 0.4.0

The freeze cut before the October public flip. Its two breaking changes were each decided in an
accepted ADR while the scope is still restricted. Until the flip, only fixes ship, as `0.4.x`
patches.

**Breaking**

- **`react` requires the New Architecture** ([ADR-0002](docs/design/adr-0002-worklets-migration-and-new-arch-floor.md)).
  It now peers `react-native-reanimated >=4.0.0` and `react-native-worklets >=0.7.0`, and dispatches
  the native scene capture through `scheduleOnUI` instead of Reanimated's deprecated `runOnUI`. Every
  `@flare-engine/create` template already ships both at these versions.
- **`render` — `SpriteDrawCommand` gains three required fields**, `blend`, `flipX` and `flipY`
  ([ADR-0006](docs/design/adr-0006-sprite-command-required-fields.md)). Code that builds a command
  literal must supply them.

**New**

- **`@flare-engine/create`**, first publish — the scaffolder, now inside the scope
  ([ADR-0007](docs/design/adr-0007-scaffolder-is-flare-engine-create.md)). Run
  `npm create @flare-engine my-game` or `bunx @flare-engine/create my-game`. The unscoped
  `create-flare-app` belongs to an unrelated package; `flare new` now runs `@flare-engine/create`
  pinned to the CLI's own version.
- **`render`** — additive blend, `flipX` / `flipY`, `drawNineSlice`, and opt-in `cullBounds` on the
  sprite batch.
- **`particles`** — emitter shapes, and `drawParticles` to queue live particles into a caller-owned
  sprite batch.
- **`physics`** — minimum-translation vectors and a broadphase-backed world raycast. Exactly-touching
  shapes now never collide, across every shape pair.
- **`math`** — curves, segment intersection points, and RNG state.
- **`errors`** — captures the crashes `ErrorBoundary` cannot see.

**Fixes**

- **`react`** — `<GameView>` rendered a black frame on device; the native capture surface is now
  built on the UI thread. The `safeArea` zero-insets fallback the docs promised now exists.
- **`storage`** — `DocumentStore.load()` no longer writes a fallback over a stored document it could
  not read.
- **`pathfinding`** — the open-set heap grows instead of corrupting past 4096 entries.
- **`ecs`** — `Query` removal is O(1).
- **`cli`** — `flare tiled-to-flare` emits Tiled-shaped JSON that `parseTiled` accepts.
- **`input`, `deep-links`** — URL and input parsing hardened against inherited keys and non-finite
  values.
- **`engine`** — declares the `react-native-reanimated` peer on the barrel.

**Published-surface settlement** ([ADR-0004](docs/design/adr-0004-pre-flip-surface-remediation.md)).
The pre-flip audit's contract changes across `core`, `math`, `ecs`, `input`, `shapes`, `render`,
`render-web`, `postfx`, `react`, `scene`, `storage`, `physics`, `pathfinding`, `tilemap`, `cli`, `ui`,
`ui-shop`, `iap-revenuecat`, `leaderboards` and `devtools` — read each package's changelog before
upgrading. For example, `SceneFactory` now receives the `World` and `Camera2D` the manager created
(a zero-argument factory still type-checks), and `TileLayer.tiles` is `readonly`.

**Performance.** The new blend, flip and cull checks cost the node `render.flush` microbenchmarks
10–15% (`1000 sprites / 1 atlas` 22.8 → 26.0 µs). The CanvasKit frame lanes moved −6% to +2.5%.
See [benchmarks](docs/references/benchmarks.md).

## 0.3.1

Fixes driven by the two real consumers (Pan Tvardowski and a portfolio site), all shipped as
patches because both consumers pin `^0.3.0` and a minor would have reached neither.

- **`physics`** — uniform spatial-hash broadphase behind the existing `SpatialIndex` surface;
  the exported API is unchanged. Sparse-scene collision cost dropped from 4.82 ms to 0.18 ms at
  1000 bodies.
- **`react`** — `VirtualButton` and `VirtualJoystick` can now be used together; pointer identity
  comes from the touch event instead of a hard-coded id 0.
- **`ui`** — `Label` gained `numberOfLines` / `ellipsizeMode` / `adjustsFontSizeToFit` /
  `minimumFontScale`; `style` widened to `StyleProp<…>` across all eight prop declarations.
- **`ecs`** — optional `query?` on `createLifetimeSystem` and `createBoundsCullSystem`, so callers
  can supply a pre-registered query instead of the systems minting their own.
- **`postfx` / `render`** — `uniforms` widened to `Float32Array | number[]`, removing an
  `as unknown as` bridge from a consumer that bans `any`.
- **`physics`** — `getColliderBounds` / `getColliderBoundsInto` on `CollisionWorld`.
- **`scene`** — a generation token retires stale `onPreload` handlers, fixing an activation stall.
- **`dynamics`** — `BodyOptions`, `WorldOptions` and `isStatic` exported from the barrel.

## 0.3.0

The consumer-enablement release: the first cut with real external consumers of the packages it
ships.

- **Web target.** `<GameView>` renders in a browser from the same source that builds the native
  app; all three `create-flare-app` templates gained web support, and two per-frame leaks in the
  web scene-capture path were fixed.
- **New package: `@flare-engine/dynamics`** — rigid-body dynamics, its first release.
- **Toolchain.** Bundling moved from `tsup` to `tsdown`, lint to Biome 2, the TypeScript floor to
  5.9. Dist output is byte-compatible; no runtime or public API change.
- **Packaging.** Every manifest declares `engines: { node: ">=20" }`, and per-condition type
  declarations mean an ESM consumer resolves `.d.mts` rather than falling back to the
  CommonJS-flavoured `.d.ts`.
- **Documentation truth pass.** Every `ts`/`tsx` README example now typechecks against the
  workspace, enforced in CI by `bun run check:readme`.
- **Correctness.** The bulk of the pre-launch audit rows (`OSS-B*`), plus perf-observability
  counters and a hot-loop `__DEV__` guard.

## Conventions

- **Lockstep.** Never bump a single package. A release moves every `@flare-engine/*` together.
- **Never a major.** A major on any package would force the whole lockstep set to 1.0.0.
- Releases are cut with Changesets; see [`AGENTS.md`](AGENTS.md) for the commit and versioning
  contract.
