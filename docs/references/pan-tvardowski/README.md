# Pan Tvardowski — Folio Archive (retired)

The 21 PNG folios in [`folios/`](folios/) are **retired historical design decks**. They
predate the Kenney placeholder-sprite swap and the typed visual-spec rebuild; nothing in
them is authoritative. The canonical visual source of truth is the typed
[`src/visual-spec/`](https://github.com/grzott/Pan-Tvardowski/tree/main/src/visual-spec)
modules in the [Pan Tvardowski repo](https://github.com/grzott/Pan-Tvardowski)
(since 2026-06-08), cross-indexed by its
[`docs/visual-reference.md`](https://github.com/grzott/Pan-Tvardowski/blob/main/docs/visual-reference.md).

Kept for design-history reference only.
